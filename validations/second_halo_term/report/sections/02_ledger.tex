\section{Unit and cosmology ledger}
\label{sec:ledger}

Cross-code comparisons on this chain have historically failed on
conventions, not physics. The harness therefore fixes one explicit
ledger, enforced programmatically: every exchange file
(\texttt{.npz}) carries unit strings, and the comparison script refuses
to compare arrays whose declared conventions differ before conversion.
The factor $10^{12}$ appearing throughout is the area conversion
$1\,\mathrm{Mpc}^2 = 10^{12}\,\mathrm{pc}^2$.

Fiducial cosmology (the checked-in dump's
\blk{cosmological\_parameters}): $\Omega_{m,0} = 0.311049$, $h = 0.6766$,
$\sigma_8 = 0.8238$, $n_s = 0.9665$, $\Omega_{b,0} h^2 = 0.02242$,
$m_\nu = 0$, $w = -1$;
$\rho_{c,0} = 2.77533742639\times10^{11}\,M_\odot\,h^2/\mathrm{Mpc}^3$.
CLensPy is \emph{under test} here, not a gospel reference: its
\pyfile{lensing/profile.py} normalized the $\Sigma$ and
$\Delta\Sigma$ two-halo paths inconsistently and evaluated $\rho_m$ at
$z_{\rm cluster}$ (both since fixed in the working copy --- the
convention is now $\Omega_{m,0}\,\rho_{c,0}$ everywhere), so the
harness uses the raw \texttt{TwoHaloTerm} transforms with its own
conversions (Section~\ref{sec:remaining} lists all CLensPy findings).
