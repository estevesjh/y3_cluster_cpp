\section{The fix and the $\Delta\Sigma$-method decision}
\label{sec:fix}

\paragraph{Fix.} In \modname{ct\_2hTerm}
(\pyfile{y3\_buzzard/haloModel.py}): the per-$z$ loop now indexes
$P(k, z_i)$ (with a shape assertion); both NaN clips are removed; the
$M_d/10$ inconsistency is repaired; the in-place mutation that
contaminated the published $\Shh$ with the dummy-NFW profile is gone;
and the broken \texttt{zvec=None} branch delegates to the common path.
The call site (\texttt{Md=1e14, cd=5}) is textually unchanged --- those
values now parameterize only cluster\_toolkit's inner-edge extension
and the optional stabilizer.

\paragraph{The sandwich is stabilization, not physics.}
\texttt{DeltaSigma\_at\_R} must extrapolate $\Sbar$ below the table
edge assuming an NFW$(M_d, c_d)$; adding an analytic
$\Sigma_{\rm NFW}$ before and subtracting the same halo's analytic
$\Delta\Sigma_{\rm NFW}$ after makes that extrapolation valid and, with
a \emph{consistent} $M_d$, cancels the dummy exactly. Both the
first-principles bench and the fiducial run confirm the
dummy-independence (cancellation residual \cancResidual{} of the
$\Delta\Sigma$ peak between $M_d{=}10^{14}, c_d{=}5$ and
$M_d{=}10^{13}, c_d{=}4$). What no sandwich can recover is the
\emph{two-halo term's own} interior mass below the table edge --- which
is why the method decision below is not a tie.

The shipped default is \texttt{dsigma\_method='direct'}: $\Sigma_{2h}$
evaluated from the per-$z$ $\xi$ on a grid extended to
$R = 10^{-3}$ cMpc$/h$ and $\Sbar$ integrated by cumulative trapezoid
--- the interior mass is integrated, not modeled, and no free
$(M_d, c_d)$ enters the result. The sandwich remains selectable for
comparison.
