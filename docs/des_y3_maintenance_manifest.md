# DES Y3 Phase 1 Maintenance Manifest

## Status and authority

This document implements Phase 1 of the
[new-module layout proposal](module_reorganization_plan.md). It records the
current DES Y3 validation baseline without moving or modifying any source,
module, model, test, CMake target, or runtime path.

The layout proposal was approved on 2026-08-11 (see its Status section), so
the six stages below are now the standing validation baseline for Phase 2
work under `src/pipelines/des_y3/`. The Phase 1 boundary at the end of this
document still holds for the baseline itself: Phase 2 adds new
implementations next to these stages and never edits them.

The source contracts below were audited against `y3_cluster_cpp` commit
`29949bdfecda00eea938eae194ac9f3a1d5fad1e` on 2026-08-11. The external
pipeline is pinned independently below. For runtime options, the pinned
pipeline configuration is authoritative. For the actual DataBlock reads and
writes, the module source is authoritative; this manifest must be updated if
an approved change alters that interface.

## Configuration-grid contract

These are setup-time options, not per-sample DataBlock values. The full
option values remain pinned by `mock_mcmc_buzzard.ini`.

| Stage | Grid contract in the pinned pipeline |
|---|---|
| `sel_function` | Twelve equal-length `lam_min`, `lam_max`, `zob_min`, `zob_max`, and `sigma_z` arrays; shared `(lnM,z)` table with `n_lnm=192`, `n_z_shared=64` |
| `NumCountsSel` | `bin_index = 0 ... 11`; fixed GL defaults `n_lnm=96`, `n_z=64`; output length 12 |
| `Shear1hMisSel` | Cartesian product of 12 `bin_index` values and 15 `r_perp` values, bin slow and radius fast; output length 180; `method=exact` unless explicitly overridden |
| `b_sel_marg` | Zipped wall of twelve `(zo_low, zo_high, lambda_bin)` points, with richness index fastest; output length 12 in each of three sections |
| `bsel` | `lob=(25,37.5,52.5,130)`, `zob=(0.275,0.425,0.575)`, and a 32-node legacy `theta` grid; it reshapes the three C++ arrays using these configured axes |
| `shear_prj_frozen_physics` | Zipped 180-point `(lambda_bin, zo_low, zo_high, radii)` wall; 12 bins by 15 radii, bin slow and radius fast |

The adaptive-Cuhre options still present in the `NumCountsSel` and
`Shear1hMisSel` sections are compatibility-only and are ignored by their
current fixed-GL evaluators.

## DataBlock contracts and shared dependencies

CosmoSIS normalizes section and key names, so source spellings such as
`haloModel`/`halomodel` and `omega_M`/`omega_m` refer to the same contract.
Shapes below are the pinned 12-bin, 15-radius configuration.

### `sel_function`

Inputs:

| DataBlock key | Contract |
|---|---|
| `cluster_mor/{log10_Mmin, alpha, epsilon, sigma_lambda}` | Required HOD parameters |
| `cluster_mor/log10_ratio` or `cluster_mor/log10_M1` | Required alternative parameterizations of $M_1$; `log10_ratio` wins when both exist |
| `cluster_mor/z_pivot` | Optional; defaults to 0.45 |
| `plob_ltr_params/{z, a_tau, b_tau, a_mu, b_mu, a_sig, b_sig, a_fprj, b_fprj}` | Optional EMG coefficient table; falls back to `PrjParams.default()` |

Outputs:

| DataBlock key | Units and shape | Consumer |
|---|---|---|
| `sel_function/lnM` | $\ln(M_\odot/h)$, `(192,)` | `NumCountsSel`, `Shear1hMisSel` |
| `sel_function/z` | true redshift, `(64,)` | same |
| `sel_function/S_stack` | dimensionless, `(12,64,192)` with layout `(bin,z,lnM)` | same |

Shared implementation dependencies are NumPy, SciPy, and
[`y3_buzzard/prj_params.py`](../y3_buzzard/prj_params.py). Its HOD and EMG
kernels intentionally mirror [`mor_hod_t.hh`](../src/models/mor_hod_t.hh)
and [`richness_kernel_t.hh`](../src/models/richness_kernel_t.hh).

### `NumCountsSel`

Inputs:

| DataBlock key | Contract |
|---|---|
| `sel_function/{lnM,z,S_stack}` | The packed selection tensor above |
| `mass_function/{m_h,z,dndlnmh}` | HMF axes and $dn/d\ln M$ table |
| `cluster_abundance/{hmf_s,hmf_q}` | HMF nuisance correction |
| `distances/{z,d_a}` | Angular-diameter-distance table used by $dV/d\Omega dz$ |
| `cosmological_parameters/{h0,omega_m,omega_nu,omega_lambda,omega_k}` | Volume element and HMF mass-axis conversion |

Output:

| DataBlock key | Units and shape | Consumer |
|---|---|---|
| `numcountssel/vals` | expected counts, `(12,)` | `likelihoods`; denominator of the one-halo shear stack |

The direct model dependencies are `SelGLCore`, `SelFunction_t`, `HMF_t`,
`DV_DO_DZ_t`, and `OMEGA_Z_DES`. Fixed GL nodes are supplied by the existing
`p_op_detail` helpers. The module is the $f=1$ specialization and performs
the exact redshift contraction followed by a one-dimensional mass sum.

### `Shear1hMisSel`

Inputs are the complete `NumCountsSel` input contract plus:

| DataBlock key or data file | Contract |
|---|---|
| `haloModel/{r_sigma,lnM,dSigma_nfw}` | Centred NFW $\Delta\Sigma(R,M)$ interpolation table |
| `average_sigma_crit_inv/{zlense,sci_average}` | Source-averaged $\Sigma_{\rm crit}^{-1}(z)$ table |
| `miscentering/{f_mis,tau_mis}` | Optional nuisance parameters; defaults are 0.22 and 0.17 |
| `cosmological_parameters/omega_m` | Multiplicative mean-density factor for the miscentred table |
| `data/nfw_off_center/*gamma*` | Fixed, gamma-kernel miscentred NFW lookup tables loaded at module construction |

Output:

| DataBlock key | Units and shape | Consumer |
|---|---|---|
| `shear1hmissel/vals` | count-weighted $N_{ij}\!\left[\gamma_t^{1h,\rm full}\right]\!(R)$, `(180,)` | `likelihoods`, after division by `numcountssel/vals` |

The direct model dependencies are all `NumCountsSel` dependencies plus
`NFW_DSIGMA_MIS`, the centred `haloModel/dSigma_nfw` interpolator, and the
`average_sigma_crit_inv` interpolator. The default `method=exact` contracts
redshift once and performs the full fixed-GL mass sum. The optional
`method=idea2` is an experimental second-order mass-moment approximation;
it computes profile finite differences at runtime and is not the proposed
offline `radial_series` implementation.

### `b_sel_marg`

Inputs:

| DataBlock key | Contract |
|---|---|
| `mass_function/{m_h,z,dndlnmh}` and `cluster_abundance/{hmf_s,hmf_q}` | HMF through `HMF_t` |
| `cluster_mor/{log10_Mmin, log10_ratio \| log10_M1, alpha, epsilon, sigma_lambda}` | Shifted-Poisson HOD parameters; optional `z_pivot` is supported |
| `distances/{z,d_a,d_c}` | Volume and comoving-distance tables |
| `haloModel/{lnM,z,bias}` | Halo-bias interpolation table |
| `xi_nl/{r,z,xi_nl}` | Nonlinear correlation-function table |
| `cosmological_parameters/{h0,omega_m,omega_nu,omega_lambda,omega_k}` | Unit conversion, HMF mass convention, and volume element |

Outputs:

| DataBlock key | Units and shape | Consumer |
|---|---|---|
| `b_sel_marg_P1/vals` | $P_1=\mathcal P[1]$, `(12,)` | `bsel` |
| `b_sel_marg_I1/vals` | $I_1=\mathcal P[b\xi_{\rm NL}\sigma]$, `(12,)` | `bsel` |
| `b_sel_marg_J/vals` | $J=I_2-I_1$, evaluated directly, `(12,)` | `bsel` |

The direct model dependencies are `P_operator`, `HMF_t`, `DV_DO_DZ_t`,
`MOR_HOD_t` parameter accessors, the compiled
[`z_kernel_data.hh`](../src/models/z_kernel_data.hh) table, halo-bias and
$\xi_{\rm NL}$ interpolators, and fixed-GL helpers from
[`p_operator_cuhre_t.hh`](../src/models/p_operator_cuhre_t.hh). The three
outputs are co-computed by one target and must remain on the same wall grid.

### `bsel`

Inputs:

| DataBlock key | Contract |
|---|---|
| `b_sel_marg_{P1,I1,J}/vals` | Three `(12,)` operator arrays, reshaped using the configured `zob` and `lob` axes |
| `mass_function/{m_h,z,dndlnmh}` | HMF used for $b_{\rm eff}$ and the latent-richness prior |
| `haloModel/{m_h,z,bias}` | Halo-bias table |
| `cluster_mor/{log10_Mmin, log10_ratio \| log10_M1, alpha, epsilon, sigma_lambda}` | HOD parameters |
| `distances/{z,d_c}` | Comoving distance for $\theta_\lambda$ |
| `cosmological_parameters/{h0,omega_m}` and optional `omega_nu` | Distance conversion and HMF mass-axis rescaling |

Outputs:

| DataBlock key | Units and shape | Consumer |
|---|---|---|
| `b_sel_marginalised/{lob,zob}` | bin-centre axes, `(4,)` and `(3,)` | `shear_prj_frozen_physics` |
| `b_sel_marginalised/{b_small,b_large}` | analytic bias plateaus, each `(3,4)` with layout `(zob,lob)` | `shear_prj_frozen_physics` |
| `b_sel_marginalised/b_eff` | unselected halo-bias aggregate, `(3,4)` | diagnostics |
| `b_sel_marginalised/theta` | legacy angular axis in radians, `(32,)` | legacy consumers |
| `b_sel_marginalised/vals` | backward-compatible $b_{\rm sel}(\theta)$ table, `(4,3,32)` with layout `(lob,zob,theta)` | legacy consumers |

The direct implementation dependencies are NumPy, SciPy, and the fixed EMG
coefficient table from [`y3_buzzard/prj_params.py`](../y3_buzzard/prj_params.py).
The downstream maintained contract is the pair `(b_small,b_large)`; the
theta table is retained for compatibility.

### `shear_prj_frozen_physics`

Inputs:

| DataBlock key or data file | Contract |
|---|---|
| `mass_function/{m_h,z,dndlnmh}` and `cluster_abundance/{hmf_s,hmf_q}` | HMF through `HMF_t` |
| `haloModel/{lnM,z,bias}` | Halo-bias interpolation table |
| `xi_nl/{r,z,xi_nl}` | Nonlinear correlation-function table |
| `distances/{z,d_a,d_c}` | Volume and transverse/line-of-sight geometry |
| `b_sel_marginalised/{lob,zob,b_small,b_large}` | Selection-bias axes and analytic plateaus |
| `average_sigma_crit_inv/{zlense,sci_average}` | Optional in source, but required for non-zero shear outputs |
| `cosmological_parameters/{h0,omega_m,omega_nu,omega_lambda,omega_k}` | Unit conversion, NFW amplitude, HMF convention, and volume element |
| `data/nfw_off_center/*single*` | Fixed single-offset NFW $\Delta\Sigma$ tables loaded at construction |

Outputs are nine arrays of length 180:

| DataBlock key | Units | Consumer |
|---|---|---|
| `dsigma_prj_frozen_physics/{vals,rnd,cl}` | $M_\odot/(h\,\mathrm{pc}^2)$; total, random, clustered | diagnostics |
| `shear_prj_frozen_physics/{vals,rnd,cl}` | dimensionless; total, random, clustered | diagnostics |
| `shear_prj/{vals,rnd,cl}` | exact alias of the preceding shear arrays | `likelihoods` |

The direct model dependencies are `ShearPrjFrozenPhysics`, shared geometry
and grid helpers in [`sigma_prj_t.hh`](../src/models/sigma_prj_t.hh),
`HMF_t`, `DV_DO_DZ_t`, `OMEGA_Z_DES`, `NFW_DSIGMA_MIS` with the `single`
kernel, `z_kernel_data.hh`, and the halo-bias, $\xi_{\rm NL}$, distance, and
$\Sigma_{\rm crit}^{-1}$ interpolators. The pinned configuration must retain
`include_omega_z=0`.

## Current numerical-strategy mapping

| Proposed strategy | Current correspondence | Phase 1 classification |
|---|---|---|
| `full_ltmz` | No complete maintained DES Y3 implementation yet. `NumCountsFullScalarIntegrand` is a useful triple-integral diagnostic, but it explicitly omits photo-$z$ and miscentering and is not promoted into this contract. | Future work; diagnostic remains at its current path |
| `fast_mass` | `NumCountsSel` / `NumCountsSelGL`: exact redshift contraction followed by the fixed-GL mass sum for $f=1$. | Current production implementation |
| `radial_series` | No current stage implements the complete offline $U_0$--$U_3$ table design. `Shear1hMisSel` provides the exact redshift-contracted mass sum and an experimental runtime second-order `idea2`; `ShearPrjFrozenPhysics` is a distinct frozen-physics fixed-grid approximation. | Future implementation; current stages are validation baselines |

`sel_function`, `b_sel_marg`, and `bsel` are prerequisite selection stages,
not competing integration strategies for the final count or shear
observable.

## Phase 1 boundary

Phase 1 is documentation-only. This manifest does not authorize:

- moving or renaming any current entry point;
- changing the six DataBlock contracts above;
- changing a CMake target or `.so` path;
- modifying an existing C++ module or integration template;
- promoting `idea2`, `NumCountsFullScalarIntegrand`, or
  `ShearPrjFrozenPhysics` to a different scientific status;
- beginning a Phase 2 implementation.
