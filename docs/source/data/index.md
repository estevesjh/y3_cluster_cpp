# Data and calibration files

Inventory of every external file in the repository's `data/` tree and of
the out-of-repo inputs the reference pipeline needs.
**Goal: no unexplained data file enters the likelihood.**

## Inventory

The `data/` tree mixes three kinds of content: files opened at runtime by
the reference `mock_mcmc_cp_camb` pipeline (*pipeline input*), files read
or regenerated by the Catch2 tests in `test/` (*test fixture*), and
legacy material no code in `src/`, `test/`, or `y3_buzzard/` references
any more (*retired/unused*). Note that `data/.gitignore` contains
`*.out`, so every `.out` file below is a gitignored test-run diagnostic
dump, not tracked reference data; several tests have since moved their
dumps to `validation-data/`, leaving stale `.out` copies here.
